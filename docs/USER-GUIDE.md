# OPENREELpy - USER GUIDE

## Page 1 - Searching Open Media

Enter a clear topic in the main search box. Good examples include “silent comedy films”, “early space exploration documentary”, “computer history films” or “jazz concert”. Choose SEARCH or press Enter. Suggested topic chips run the same workflow.

OPENREELpy rejects empty searches, searches over 300 characters and requests containing clear piracy or access-bypass wording. Rewrite a refused query as a lawful topic, historical period, creator or educational subject.

The search-results dialog first displays the editable Google dork. Under it, OPENREELpy displays up to twenty-four public open-media records returned by Internet Archive.

## Page 2 - Using the Results Index

Review titles, descriptions, dates and view totals. PLAY does not immediately trust a thumbnail or record label. It requests the complete source metadata and verifies at least one non-private file with a supported video extension or recognised video format.

SAVE adds a record to the watchlist. DETAILS opens the complete Internet Archive record in a separate tab. Inspect this page for rights information, uploader notes, full file lists and any usage restrictions.

Edit the dork when you want to add or remove terms. COPY copies the latest edited text. OPEN GOOGLE automatically follows edits. SAVE SEARCH records the request and edited query in HISTORY.

## Page 3 - Watching a Video

After verification, the video opens in its own scrollable modal. The native player provides play, pause, timeline, volume and picture-in-picture or casting features supported by the browser. OPENREELpy also supplies Play/Pause, minus ten seconds, plus ten seconds, speed selection, Fullscreen and Watchlist controls.

Choose a speed from 0.75 to 2. Fullscreen uses the browser Fullscreen API. Close the modal with X or the backdrop; OPENREELpy pauses the current video first. A playback failure displays a message and source-record link so another format can be tried externally.

The description and creator information beneath the player help establish context. The source link is always present because the original record is authoritative for rights and provenance.

## Page 4 - Watchlist, History and Documentation

WATCHLIST shows saved video records. HISTORY shows searches and played items in newest-first order. Select a video entry to inspect and play it again. Select a search entry to repeat the search. The dashboard combines saved items with recently played unique items.

CLEAR removes the OPENREELpy watchlist, history and saved searches after confirmation. It does not remove unrelated browser storage. The deletion cannot be undone.

README, USER-GUIDE, FUNCT-GUIDE and TESTS are available from header and footer. CONTACT loads the required Raiiarcomio page in a sandboxed frame and provides a direct fallback when the remote server prohibits embedding.

## Page 5 - Accessibility, Safety and Troubleshooting

Use Tab and Shift+Tab to move between controls, Enter or Space to activate buttons and Escape to close a dialog. Native video keyboard shortcuts depend on the current browser. Visible focus remains on a high-contrast outline.

If no results appear, simplify the topic or use OPEN GOOGLE. If results appear but PLAY reports no file, open DETAILS and inspect available formats. If a video starts slowly, wait for metadata or try a smaller file through the source page. Network speed and Archive capacity are outside OPENREELpy control.

Do not assume “downloadable” means unrestricted reuse. Confirm the item’s licence and jurisdiction. Never use OPENREELpy to search for leaked, pirated, DRM-protected or otherwise unauthorised copies.
